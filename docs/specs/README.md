# Спецификации WitcherKM.Workflow

Canonical specs описывают согласованное поведение. [Словарь](domain/glossary.md) и [модель](domain/model.md) задают предметные понятия и инварианты; [сценарии](application/workflow.md) — действия приложения; [интерфейс](ui/workflow.md) — наблюдаемое поведение страниц. [Архитектура](../architecture/overview.md) и [дизайн](../design/frontend.md) описывают технические и визуальные решения.

Порядок изменений: `changes/active` → canonical specs → код → проверки → `changes/archive`. [Открытые вопросы](questions.md) не являются требованиями.
