# Интерфейс

Сценарии и ошибки — в [application spec](../application/workflow.md).

## Навигация и списки

Главная страница показывает цепочки, поиск по названию и фильтр по категории. Фильтр раскрывает список категорий; выбранный пункт заметен, «Все категории» снимает фильтр. Список можно открыть, выбрать пункт и закрыть с клавиатуры; Escape и клик вне списка закрывают его без изменения выбора. У каждого элемента есть переход к карточке. Страница категорий показывает справочник с поиском по имени, добавлением, редактированием и удалением. Из строки категории можно открыть список связанных цепочек через фильтр. Отдельного списка всех шагов нет.

## Карточки

Карточка цепочки показывает название, категории и упорядоченные шаги. Название и категории редактируются; шаг можно добавить, удалить и перетащить выше или ниже. У цепочки может не быть шагов. Карточка шага находится внутри маршрута цепочки, показывает автоматически рассчитанное название при пустом имени и отрендеренное описание. Название и Markdown редактируются там же. Текстовый редактор даёт предпросмотр Markdown и подсветку кода с языком в блоке.

## Изображения и удаление

Вставка изображения из буфера в редактор загружает файл и вставляет Markdown-ссылку в позицию курсора. Вставка обычного HTTP(S) URL изображения оформляет его как Markdown-изображение; вставленная готовая Markdown-ссылка на изображение сохраняет свой вид. При сохранении шага внешние изображения загружаются локально, а ссылки заменяются. Если загрузка не удалась, исходная ссылка остаётся и интерфейс показывает предупреждение. Изображение видно в предпросмотре и сохранённой карточке. Удаление категории, цепочки или шага требует явной кнопки подтверждения «Да, удалить»; отказ или отмена не меняют данные.

## Состояния

Для списков и карточек предусмотрены загрузка, пустое состояние, ошибка с повтором и видимая ошибка сохранения. Во время записи повторная отправка недоступна. Формы и диалоги доступны с клавиатуры, фокус заметен. Учетных записей нет.
