# Словарь

- **Цепочка действий** — описанная пользователем последовательность шагов для достижения результата. Подробные правила её жизненного цикла пока не согласованы.
- **Шаг** — часть цепочки, объясняющая одно действие. Форматы содержания и вложений пока не определены.
- **Категория** — способ группировать цепочки для поиска. Структура категорий и правила привязки пока не определены.

Здесь нет утверждённых агрегатов, состояний и инвариантов. Их следует определить до реализации предметной модели.
