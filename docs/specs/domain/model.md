# Предметная модель

## Имена

Имя категории и цепочки обязательно. При сохранении пробелы по краям удаляются, последовательности внутренних пробельных символов становятся одним пробелом, первая буква становится заглавной, остальные символы сохраняют регистр. `База данных` и `   база   данных   ` дают `База данных`; `Базаданных` — иное имя. Уникальность определяется сравнением нормализованных имён без учёта регистра. Пустое после нормализации имя запрещено. Правило действует при создании и переименовании и отражается в базе и UI.

## Категория

Категории не вложены. Категорию можно удалить только когда ни одна цепочка её не использует. Имя можно менять при сохранении уникальности.

## Цепочка

Название уникально по тому же правилу. Цепочка всегда связана как минимум с одной категорией. Категории можно добавлять и отвязывать, пока это правило соблюдается. Создание с нулём шагов допустимо. Удаление цепочки удаляет все её шаги. Шаги одной цепочки не принадлежат другой.

## Шаг

Порядок шагов в цепочке начинается с 1 и не содержит пропусков. Новый шаг добавляется в конец. Перестановка меняет порядок и пересчитывает номера. Имя и описание могут быть пустыми; без имени отображаемое название — `Шаг {номер}`. Описание хранится как Markdown, в том числе ссылки на изображения и блоки кода с указанием языка.
