# Сценарии приложения

Предметные ограничения — в [модели](../domain/model.md). Все записи выполняются атомарно. Ошибка валидации или конфликт имени не изменяют существующие данные.

## Категории

- Получить список категорий с поиском по имени.
- Создать категорию по имени; вернуть созданный объект или ошибку пустого/занятого имени.
- Открыть категорию и связанные с ней цепочки.
- Переименовать категорию с теми же правилами.
- Удалить категорию; если есть хотя бы одна связанная цепочка, вернуть отказ. Категорию можно сначала отвязать от цепочек.

## Цепочки

- Получить список цепочек с поиском по имени и необязательным фильтром одной категории.
- Создать цепочку с названием и непустым набором существующих категорий; шаги не обязательны.
- Открыть карточку цепочки со списком категорий и шагов.
- Изменить название и набор категорий с сохранением уникальности названия и минимум одной связи.
- Удалить цепочку со всеми её шагами.

## Шаги

- Добавить шаг в конец цепочки с необязательным названием и описанием Markdown.
- Открыть карточку шага по цепочке и шагу.
- Изменить название и описание, удалить шаг или перенести его на заданное место в этой цепочке; после удаления и переноса номера пересчитываются.

## Изображения

- Принять вставленное из буфера изображение, сохранить файл в локальной папке приложения и вернуть Markdown-совместимую ссылку.
- Отдавать локальное изображение по ссылке. При создании или изменении шага скачать внешние HTTP(S) изображения из Markdown в локальную папку и заменить URL на локальный.
- Для точной внешней ссылки, включая параметры URL, повторно использовать уже скачанный файл во всех шагах. Если источник по той же ссылке изменился, обычное сохранение использует прежний файл. Разные параметры URL означают разные источники.
- Если отдельное изображение скачать не удалось, сохранить исходную внешнюю ссылку и вернуть предупреждение для интерфейса; остальные данные шага сохраняются.
- После удаления изображения из описания, шага или цепочки удалить локальный файл, если на него больше нет ссылок в шагах. Отказ в сохранении не удаляет файл, на который ссылаются данные.
