# Категории, цепочки и шаги

Источник: обсуждение с владельцем 22 октября 2026 года.

## Цель

Локальное личное приложение для хранения цепочек действий с категориями, упорядоченными шагами, Markdown и изображениями. Реализовать предметные сценарии, API через контроллеры и React UI.

## Область

- Категории: уникальное нормализованное имя, список/поиск, создание, изменение, удаление только без связей, просмотр связанных цепочек.
- Цепочки: уникальное нормализованное имя, минимум одна категория, список/поиск/фильтр, создание без шагов, изменение, удаление вместе с шагами.
- Шаги: существуют только внутри цепочки, автоматическая нумерация, перетаскивание, необязательное имя и описание Markdown, карточка шага.
- Изображения: вставка из буфера, локальное хранение, Markdown-ссылка, загрузка внешнего изображения при сохранении шага, повторное использование файла для той же ссылки, удаление неиспользуемого локального изображения.
- Без учётных записей; подтверждение удаления явной кнопкой.

## Canonical

`domain/glossary.md`, `domain/model.md`, `application/workflow.md`, `ui/workflow.md`, `architecture/overview.md`, `design/frontend.md`.

## Критерии

1. Нормализация имён и запрет дублей работают для категорий и цепочек; отказ не меняет данные.
2. Категорию нельзя удалить, пока она связана; из цепочки можно отвязать, сохранив хотя бы одну категорию.
3. Цепочка создаётся без шагов, удаляется вместе с ними; шаги добавляются, редактируются, удаляются и переставляются с пересчётом номера.
4. Списки ищутся по имени; цепочки фильтруются по категориям; из категории доступны её цепочки.
5. Markdown, код и изображения отображаются безопасно; вставка скриншота из буфера создаёт локальный файл и ссылку.
6. Состояния загрузки, ошибок, пустого списка и подтверждение удаления доступны в UI.
7. HTTP-маршруты реализованы через контроллеры; Program.cs содержит только настройку и запуск.
8. Вставленный URL изображения и Markdown-изображение с внешним URL при сохранении становятся локальными. Повтор той же точной ссылки использует сохранённый файл, включая учёт параметров URL. При неудаче исходная ссылка сохраняется и показывается предупреждение.

## Проверки

Проверки затронутого поведения: domain и HTTP сценарии на отдельной базе; frontend lint/build и ручной проход ключевых UI действий. Не тестировать не затронутую функциональность.

## Вопросы

Нет блокирующих вопросов. Для карточки шага выбрана отдельная страница внутри цепочки; это разрешено владельцем.

## Результат

Категории, цепочки и шаги реализованы в доменной модели, MediatR-сценариях, SQLite и React. HTTP-маршруты вынесены в MVC-контроллеры. Внешние изображения сохраняются локально с повторным использованием по точному URL; ошибка загрузки оставляет исходную ссылку и показывает предупреждение.

Проверено: `dotnet build`, `npm run lint`, `npm run build`, HTTP smoke (37 проверок) на отдельной базе, кэш изображений (7 проверок) на временной SQLite, браузерные действия с категориями, цепочками, Markdown, вставкой скриншота и обычного URL.
