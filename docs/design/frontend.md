# Визуальная основа

Текущий каркас использует спокойную светлую поверхность, контрастный тёмный текст и один акцентный цвет. Интерфейс должен ясно показывать состояние связи с API и не изображать несуществующие цепочки или действия.

Когда будут согласованы страницы, развивай общий стиль и проверяй читаемость, фокус клавиатуры и состояния загрузки/ошибки. Дизайн Planner можно использовать как пример организации компонентов, но его предметные карточки и декор не переносятся автоматически.
