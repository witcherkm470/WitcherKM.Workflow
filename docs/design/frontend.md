# Визуальная основа

Светлая поверхность, тёмный контрастный текст и бирюзовый акцент. Стартовая страница — список цепочек; категории доступны из навигации. Цепочки показаны карточками, категории — справочником, шаги — упорядоченным списком внутри цепочки и отдельной карточкой для чтения и редактирования.

Формы показывают ошибки, загрузку и пустые состояния. Видимый фокус, понятные подписи и кнопки переноса шага дополняют перетаскивание с клавиатуры. На узком экране колонки редактора и предпросмотра переходят друг под друга.
