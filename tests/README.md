# Проверки

`http-smoke.mjs` выполняет поведенческие HTTP-проверки категорий, цепочек, шагов и изображений. Запускайте его только против API с отдельной тестовой базой. Адрес берётся из `WORKFLOW_API_URL`, по умолчанию `http://127.0.0.1:52771`. Скрипт создаёт и удаляет свои данные; для проверки удаления всей цепочки использует случайные имена.

`dotnet run --project tests/ImageCacheSmoke.csproj` проверяет повторную загрузку одной ссылки, различие параметров URL и удаление локального файла после последней ссылки. Использует временную SQLite-базу и подставной загрузчик изображения, поэтому не зависит от доступности внешнего сайта.
