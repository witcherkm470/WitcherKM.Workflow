# Проверка взаимодействий

Это процедура, а не источник продуктовых требований. Конкретные действия и состояния бери из UI spec.

## Асинхронные страницы

- Проверь загрузку, успешный ответ, пустой результат и отказ отдельно.
- При смене страницы, фильтра или объекта задержи старый ответ и верни новый первым: данные и ошибка должны относиться к актуальному запросу.
- После записи проверь актуальное чтение и сохранность несвязанных данных.

## Формы и клавиатура

- Пройди создание, редактирование, отмену и отказ для затронутого действия, если они утверждены в spec.
- Проверь Tab, Shift+Tab, Escape и возврат фокуса; обязательность полей бери из domain/application.
- Задержи сохранение: повторная отправка не должна создавать вторую запись.
- При ошибке черновик и возможность повтора должны соответствовать UI spec.
- Проверь название диалога, видимый фокус, длинные значения и узкий экран.
