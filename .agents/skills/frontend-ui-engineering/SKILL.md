Прочитай spec страницы, `docs/architecture/overview.md` и `docs/design/frontend.md`. Составь карту: действие → форма или запрос → результат → обновляемые данные. Недостающая форма — часть согласованного действия; новую операцию не придумывай.

Повторно используй существующие компоненты. Для асинхронных страниц и вложенных диалогов применяй [проверку взаимодействий](references/interactions.md); для простой визуальной правки не загружай её целиком.

Покрой изменённое поведение по [testing](../testing/SKILL.md). Проверь видимый результат, состояние ошибок, фокус и клавиатуру. Укажи, использовался ли настоящий backend.
