description: Изменяет доменную модель Workflow только по согласованным правилам; выбирает место инвариантов и внешних проверок.
---

Прочитай `docs/specs/domain/glossary.md`, spec затронутого понятия и `docs/architecture/overview.md`. Если предметное правило ещё не согласовано, не создавай сущность лишь ради заполнения пустого проекта.

Для каждого правила установи, достаточно ли состояния одного агрегата или нужны внешние данные. Найди все пути записи, чтобы ни один не обходил инвариант. Выбор Value Object и persistence делай по утверждённым требованиям и архитектуре, не по аналогии с Planner.

Новые состояния, ограничения, каскады и переходы требуют продуктового основания. Проверь разрешённые и запрещённые переходы и сохранность состояния после отказа; изменения схемы проверяй на отдельной базе.
