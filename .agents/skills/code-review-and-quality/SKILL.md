---
name: code-review-and-quality
description: Проверяет diff Workflow и его соответствие canonical specs после реализации или по запросу review; отделяет доказанные дефекты от вкусовых замечаний.
---

Прочитай change, затронутые canonical specs/architecture, diff и вызывающий код. Проверь пять аспектов: поведение и ошибки; понятность; границы слоёв; обработка входа/данных; лишние запросы и гонки.

Для каждого дефекта укажи триггер, наблюдаемое последствие, файл/строку и нарушенный контракт. Присвой приоритет по ущербу; сомнение обозначь вопросом. Не блокируй корректный код личным стилем и не добавляй требования из upstream.

Отдельно проверь отсутствие подгонки тестов по [testing](../testing/SKILL.md), соответствие UI-действий формам и полноту доказательств. Mock/browser/HTTP результаты не взаимозаменяемы.

Исправления проверь целевыми тестами. Выход — оставшиеся конкретные findings либо отсутствие найденных дефектов с границами проверки; не обещание отсутствия любых багов.
